Analysis outputs in this delivered archive were calculated from the uploaded GSE7904 series matrix using a two-sided Welch two-sample t-test per probe and Benjamini-Hochberg FDR correction. The supplied R script implements the same vectorized test and regenerates outputs in R/RStudio. R was not executed in the assistant runtime; the supplied R script is provided for local reproducibility. The signal transformation is log2(max(dChip_signal, 1)) and is disclosed in REPORT.md because the processed matrix contains non-positive values.
